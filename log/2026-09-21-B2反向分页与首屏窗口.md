## 段 1 · 已修并实测：`limit` 从「取窗口头部」改判成「始终取窗口尾部」

- 现象：第一版把 `limit` 定成「给 `before` 取尾部、只给 `after` 取头部」。看着对称，但界面半边要的是
  **首屏只拉最新一屏**——`docs/施工5-前端重构-F1-F7.md:566` 批次20 的原话是「`/events` 的 SSE 会把 `after`
  之后的全部回放完，打开会话就是一次吞下保留窗口里的 5015 条事件」。取头部语义下这条永远做不到。
- 根因：我把「翻页」当成了唯一用例，漏了「首屏」是同一枚 `limit` 的第一个消费者。
- 解决：`server/events.py` 收成单规则 `return out[-limit:] if limit > 0 else out`；
  `platforms/event_store.py` 里 `XREVRANGE` 分支不再依赖 `before` 存在（XRANGE 的 COUNT 截头部，
  带 limit 就必须走反向再翻回来）。`limit=0` 保持老「全给」语义，老调用方（SSE `:270`、`log/gate2_real_min.py`）零改动。
- 判据：`tests/s8_frontend_contract.py::t11` 新增两条断言，两台 bus 同一份剧本逐条同判——
  `history(limit=3) == [m9,m10,m11]`（不是 m0..m2）、`history(after=cur[2], limit=2) == [m10,m11]`。

## 段 2 · 已修并实测：响应回 `has_more`（多取一条判显隐）

- 判据 B2 原文只要求 `before=&limit=`，但 `施工5:566` 的正解写着「后端补 `before`+`limit`（**并回 `has_more`**）」。
  不回的代价很具体：前端只能靠「本页不足一屏」或「下一次请求拿到空页」判到底，用户会多点一次空按钮。
- 做法：路由 `limit>0` 时向 bus 要 `limit+1` 条，多出来那条既是 `has_more` 的判据、又被丢掉不回给前端；
  bus 的返回契约（list）不动，所以 SSE 与既有测试零改动。`limit=0` → `has_more=False`（本来就给全了）。
- 读数（HTTP 层，隔离实例 8721 / db15 / `SID=89df9a40`，流长 895 条）：
  `?limit=400` → 400 条 + `has_more True`，末条是 `b2blk59` 的 `end_marker`（**取的是尾部**）；
  `?before=<P1首条>&limit=400` → 400 条 + `has_more True`；再往前 → 95 条 + `has_more False`；
  不给参数 → 895 条 + `has_more False`。

## 段 3 · 已修并实测：首屏窗口化 + 页界切块的拼接顺序

- `stores/sessions.ts`：`select()` 不再直接 `connect()`，改成 `loadFirstPage()`（`?limit=400`）→
  块建完、`earliestCursor`/`hasMoreEarlier` 落位 → 才 `connect()`，SSE 从 `lastCursor` 只收增量。
  拉历史失败时退回老行为（`after=''` 整段回放），不因为新面挂掉把首屏打死。
- **真坑（这条是本次唯一「不写出来下次一定重犯」的）**：`applyEvent` 的去重靠
  `ev.cursor <= this.lastCursor → return`，反向翻页的整页游标全都更小 → 直接喂进去会被**整页丢掉**；
  而游标不往回走是 SSE 续推与 seq 去重的前提，不能为了拼历史把它倒退。
  另一头，被页界切开的那一块若直接 `tokens.push`，早半截会排在晚半截**后面**，文本顺序颠倒。
- 解法：`mergeEarlierPage()` 把整页在**临时状态**里过一遍 `applyEvent`（页内升序合并复用原来那份 switch），
  再拼回正片：已存在的块 `head.tokens.concat(tail.tokens)`，新块整块插到 `blockOrder` 最前，
  `lastCursor/lastSeq` 全程不动。日志行同理 `[...pageLogs, ...liveLogs].slice(-MAX_LOGS)`。
- 门禁：`t11` 里 45 条流的翻页剧本（满页 20 + 短页 5 + 空页停止）拼回全量不重不漏，两台 bus 同判。
