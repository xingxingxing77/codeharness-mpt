## 段 1 · 现象

一场会话用过两个币种的模型时，界面上那个「¥x.xxx」是两种币价直接相加的结果：

- `TOKEN_COSTS` 一张表里混着两种单位（`qwen3.8-flash` 等人民币/千 token 与 gpt/claude 等美元/千 token），
  `CostManager.total_cost` 是无单位 float，`:40` 直接 `+=`；
- 展示侧 `ConversationRoot.vue:11` 与 `UsagePage.vue` 一律打 `¥`，用量页那格标签写着
  「总成本（人民币价目）」——等于每一行美元模型都在给人民币计数；
- 日志行 `cost.py:41` 硬写 `$`（`Total running cost: $…`），与前端符号正好相反。

账面原话（`token_costs.py:12`）还写着「前端 "$已用"」，那条 D1 轮已核实过期（前端是 ¥）。

## 段 3 · 根因

记账口径错误 + 缺一个币种维度：`Costs` 只有一个无单位 float，「这笔钱是什么币」在数据里根本不存在，
所以展示层只能猜一个符号。修法的正确形状是**把币种提到数据结构里**（两桶 + 逐笔 `cc`），
而不是在前端做换算——换算需要一个汇率源与一个维护责任人，而我们已明确不做预算管理，
为展示引外部数据源不值（用户拍的也是这一支）。

## 段 4 · 解决方案

1. `codeharness/provider/token_costs.py`：新增 `CNY_MODELS`（21 行，两条来源分组注释）+
   登记 `step-3.5-flash`（`prompt 0.0007 / completion 0.0021`，单位元/千 token）+
   文件头写清两条边界（**没逐行对过厂商现价**，分桶只解决混加不修单价；缓存按未命中档）。
2. `codeharness/provider/cost.py`：`Costs` 第四字段改两桶（`cost_usd`/`cost_cny`，**无合计字段**）；
   `CostManager` 同名字段 + `cny_models`（可注入，门禁就是靠它造混币种读数）+
   `currency_of()` 单一判据（未登记模型回 `""`，**不冒充 USD**）；日志行改成
   `Total running cost: $x / ¥y | Current: z CNY`；`records` 每笔带 `cc`。
3. `server/runner.py`：新增 `cost_snapshot(cm)` 作为快照唯一出口（原先 `_sync_cost` 与
   `_publish_status` 各写一份 dict，字段集漂过一次的形状）；`_seeded_ledger` 只续算两桶，
   **不回读老记录里的 `total_cost`**；`_trace_span` 的 span 改带 `cost_usd`/`cost_cny` 两桶增量。
4. 前端：`types.ts`/`api/client.ts`/`utils/trajectory.ts` 的 span 形状同步；
   新 `utils/money.ts`；`ConversationRoot`/`UsagePage`/`TrajectoryTable`/`DetailsPanel` 四处
   改走 `moneyBoth`/`sumCosts`，用量页标签从「总成本（人民币价目）」改成「总成本（分币种·不换算）」。
   **布局没动**（用户定的口径：只换数据来源）。
5. 门禁 `tests/s8_runner_meter.py::t8`（该文件 7 → **8 组**）五格：
   ① 同场混两种币价时两桶分别对上单价算式；② `Costs._fields` 恰好四字段（多出「合计」即红）；
   ③ 快照 dict 键集 = 两桶 + 两 token 项，**没有** `total_cost`；④ 未知模型不入任何桶但照记 token；
   ⑤ **对照组**：`CostManager(cny_models=frozenset())` 名单清空后，`step-3.5-flash` 必须落进 USD 桶
   ——证明分桶真按名单走，不是代码里写死了两个名字。
   另：`t2`/`t4` 的种子与断言改两桶，并加一条「老记录里的 `total_cost` 不许被读回来」。
   同步改读旧字段的既有门禁：`s2_gateway`（t4/t5/t11）、`s7_platform::t7` 的 span 形状、
   `s8_frontend_contract::t6`（span 词汇表 runner==frontend 同判）。
6. 账面：`docs/前端/接口契约.md` 加 `cost` 快照形状 + `Span` 字段改两桶；
   `docs/施工4` 的「用量快照」表行与「计量真值」判据行按新字段改准。
