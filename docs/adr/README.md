# 技术决策记录（ADR）

> **分工**：本目录只收**不可逆的口径决定**（含被拒选项、重开条件、以及「取证把原方案推翻了」这类
> 只看代码看不出来的判断）。**执行状态与判据仍只有 `plan/PLAN.md` 一份真值**——§9 从 2026-09-22 起
> 降级成指向这里的指针，不允许两处各写一份结论（本仓反复踩过：两套表必须互洽，否则一定漂）。
>
> 命名与格式：`ADR-YYYYMMDD-NN-中文标题.md`，日期取**拍板当天**（`date` 现取，不推断）。
> 四段固定：状态（提议/已接受/已废弃/已替代）· 背景 · 决策 · 后果 · 相关链接。
> 审批：技术负责人（用户）批；落笔与执行归会话。**会话不自批。**
