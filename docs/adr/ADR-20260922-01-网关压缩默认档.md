已接受（2026-09-22，用户批准「按推荐的做」）

## 背景
`configs/llm_config.py:99` `context_length=None` + `:106 compress_type=NO_COMPRESS`，
门条件在 `provider/gateway.py:208`：**不设 = 永不压缩**。C5（`30bec97`）把配置入口文档化并加了值域校验，
但刻意留了「要不要给一个保守默认预算」不拍。反面事实有两条：`context_length=-1` 会让每轮上下文被裁到只剩一条
（现场只看得见模型失忆，已修成当场拒），而 thinking 模型的输出预算与上下文预算互相挤。

## 决策
**维持不设默认档**（选项 A）。压缩永远是显式选择。
配套：用量侧只**报事实**——单轮 prompt token 峰值 + `context_length` 配了没有；
**不写死告警阈值**（写死 100k 等于把刚拒绝的默认档换个形式塞回来，且不同模型预算不同）。

## 后果
正面：没有任何人的会话被静默截断；配置疏忽的后果看得见而不是猜。
负面：长会话上下文无限增长，代价是钱与延迟——但这条**可见**（计量、P95、截断提示都在）。
待办（未做）：用量面板补那两个事实（数据源现成：`server/runner.py:61` 每笔 span 带 pt/ct 增量）。
