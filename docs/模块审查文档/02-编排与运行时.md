## 1 · 模块职责与边界

- **编排面**（`team.py` + `roles/**` + `strategy/**`）负责把角色装成 LangGraph 节点并跑「think → gate → act → (ask)」这条循环：`team.py` 是装配与组队真值（经典五角色 / 动态三角色 / 招人三件），`roles/role_zero.py` 是动态线引擎（命令面、审批闸门、可重入游标、委派与回报），`roles/agent.py` 是经典线引擎（Action 游标 + REACT 决策），`strategy/**` 是两种可选执行引擎（ToT 规划器、plan-and-act 数据分析）。
- **契约面**（`schema.py`、`const.py`、`prompts/**`）是三张互洽表的数据与词汇真值：`Message` 的路由三字段、`Plan` 的状态机、`RequirementTag` 的 cause_by 词汇、prompt 的命令契约。它不许做：把同一个 tag 在两处各写一份字面量（`const.py:5-6` 自陈的一致性敏感）。
- **运行时接缝面**（`runtime.py`、`report.py`、`observability.py`、`logs.py`）是内核与 server 之间唯一的七个 ContextVar、报道协议（块事件词汇表 + sink 单出口）与 trace 接缝。它不许做：让内核依赖 server（`runtime.py:2` 「包内保持零 fastapi 依赖」），也不许让观测面有权打断业务面。
- **文档/仓库面**（`document.py`、`repo_parser.py`、`reflection.py`）是知识库读写的格式腿与自反思腿。
- 明确不在本档：`environment/team_graph.py`（route/reducer 本体，判据 s16 的主战场，只在需要证明接缝时引用）、`tools/**`、`memory/**`、`actions/**`、`server/**`。

🟡 **信任边界（审批粒度）：`_approval_key` 把触发消息的 `content` 截到 500 字，同一函数自己的 docstring 说这正是「正是要修的洞」**
