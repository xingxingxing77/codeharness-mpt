## 2. 🔴 P0 四条（按可造成的后果排序）

1. **Editor 的"异常恢复"支路会把文件静默清成 0 字节** — `codeharness/tools/libs/editor.py:514 _edit_file_impl`：
   备份写入挂在默认关的 `enable_auto_lint` 之后（`editor.py:109` 且 `editor_tools` 从不置真）⇒ 生产里 `temp_backup` 恒空，
   落到泛捕获时"用空备份盖回原文"。详见 `04` §4。
   **未造活体样本**（怎么反证写在 `04` §6）。
2. **动态线的 `memory` 是实例态，resume 换进程后整段归零** — `codeharness/roles/role_zero.py:91` + `:581-582`：
   轮次级 `results` 只经 `self.memory` 进 prompt（`plans` 已随 C71 持久），停在待人工处换 worker 恢复即"失忆重规划"，
   可把已执行的 `write_file`/终端命令再发一遍（= C59 的病换了触发条件）。经典线同族已解（`agent.py:320`）。详见 `02` §4。
3. **进程内 SSE 订阅队列仍无界** — `server/events.py:111` `asyncio.Queue()` 无 `maxsize`；
   C90 只补了 Redis 版（`platforms/event_store.py:197` 有界 + 丢了计数），而**无 Redis 才是默认档**，
   `s7 t21` 判据只测 Redis bus ⇒ 盲区。详见 `05` §4。
4. **structured 腿的超时不落 `_timeout_lost`** — `codeharness/provider/gateway.py:432-434`：
   C42/C52 那族"超时不重发/不假成功"的第三条腿，而它恰是动态线主路径。详见 `01` §4。

## 3. 🟡 P1 里我会优先处理的（其余见各文档）

- `codeharness/utils/file.py:150-152`：pdf/docx 读取链第一跳就 `import codeharness.utils.omniparse_client`，
  **该模块不在仓里**（`ls` 实测零命中），而 `_read_pdf:132` / `_read_docx:144` 都先调它 ⇒ 走到即 `ImportError`；
  唯一入口是 `tools/libs/editor.py:144 File.read_text_file`。与 C26「白名单宣称收 `.pdf`/`.docx` 但进不去」同一症状、**不同机制**。
- `tools/__init__.py:96`：模型主动调的 `search_knowledge_base` 每次现建**不带 `meter` 的 `LongTermMemory`**
  ⇒ 它的失败/命中不进 R1 的 `recall_*` 账本、也不参与 R2 短路 ⇒ 用量页的 `recall_failures=0` 在这种情况下是假话。
- `codeharness/roles/agent.py:110`：审批键把 `content` 截到 500 字，而同一函数 docstring 明写"截断正是要修的洞"
  ⇒ 差异在第 501 字之后的两笔共用一个 approval_id（批一次放行两笔）。
- `server/app.py:132-134`：body 闸读 `Content-Length`，chunked/缺该头时 pydantic 先读全段再 422 ⇒ C86 的核心保证被一个头部选择破掉。
- `codeharness/actions/write_code.py:96`：先 `unlink` BUGFIX 工单再调模型（`:114`），模型失败即丢工单。
- `codeharness/actions/edge_actions.py:25` + `tools/_approval.py:58`：`ExtractReadMe` 从任意 `readme_path` 读盘，
  而 `_PATH_KEYS` 不含该键 ⇒ `workspace_write` 会话免审越界读。
- `codeharness/logs.py:41-52`：导入期开 DEBUG 文件 sink、无 rotation/retention（实测 `logs/` 55 MB、单日 46.7 MB，
  且 `exp_pool/decorator.py:72` 把 prompt/回包全文写进去）。
- 前端一族：`DetailsPanel.vue:440` 切任意页签都重拉 fileTree+graph；`Toggle/RadioCards` 无 `role=switch` 与键盘可达；
  `ConfigPage.diagnose`「未发现问题」、`BrowserPage.clearData`「已清除」、`EnvPage` 幻影行 —— **把没做说成做了**。
