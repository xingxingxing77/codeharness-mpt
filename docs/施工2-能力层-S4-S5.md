### 重构（`重`→ 这是本步的重点）
- **R9 · Qdrant 检索层**。核实过源 `qdrant_store.py:94-124`:单 dense 向量 + `k=10`,无 named vectors、无 sparse、无 quantization,`write()` 是空 stub,裸 `except:` ×2,还在用已废弃的 `recreate_collection`。你要写的:
  - **named vectors**:一条 record 同时存 `dense`(bge-m3 1024 维)与 `sparse`(bge-m3 词权重)→ Qdrant 服务端 `fusion` 做 hybrid 召回
  - **payload 多租户**:把 `user_id` / `session_id` / `doc_type` / `project` 放进 payload 做 filter,**用单 collection + payload 隔离取代"每租户一 collection"**(N1 的前置)
  - **scalar/binary quantization** 降内存,并保留原始向量可回退
  - rerank 保留已定稿的 bge-reranker-v2-m3、粗排 k=10 → 精排 top_n=5、**离线自动降级**
- **R9 之外**:`document_store` 的 faiss/chroma/milvus/lancedb 四件**不搬**(判定表 `弃`)
- `rag/` 的 `retrievers/` `factories/`:编排结构照源,底座换 LangChain retriever。`benchmark/base.py` 201 保留(它到 S9 变 CI 门禁)
- `strategy/experience_retriever.py` **1,243 行,是 RoleZero 的命脉**,`改` 要当`重`的量级做;`tot.py` 277 判 `弃`(平台不用 ToT 搜索,`strategy` 的可插拔由 N3 承接)
- `exp_pool`:存储换 Qdrant + **Redis 命中计数排序**(源靠 LLM judge 打分选经验,`perfect_judges` 真实评测推迟到终验之后)
